# عين السوق — v1.5.2

حزمة نظيفة وغير مكررة لمشروع عين السوق.

## الموجود داخل الحزمة
- `main.dart` — واجهة الهاتف الأساسية.
- `pubspec.yaml` — إعداد مشروع Flutter.
- `main.py` — API للمنتجات والبحث بالاسم/الباركود.
- `products.json` — كتالوج تجريبي من 1000 منتج.
- `requirements.txt` — متطلبات الـAPI.
- `DATA_MODEL.md` — نموذج البيانات.
- `DATABASE_PLAN.md` — خطة قاعدة البيانات.
- `PHONE_BUILD.md` — خطوات بناء APK من الهاتف.
- `README.md` — هذا الملف.

## الوضع الحالي
هذه نسخة بداية موحدة v1.5.2. الـAPI يعمل حاليًا على `products.json` كتخزين تجريبي، تمهيدًا لربطه بقاعدة بيانات حقيقية.
